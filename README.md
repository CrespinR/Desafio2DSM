Descripción del proyecto

Aplicación móvil desarrollada en Android Studio como parte del Desafío 2 de Desarrollo de Software para Móviles.

La aplicación permite gestionar destinos turísticos mediante operaciones de registro, consulta, edición y eliminación de destinos.

Funcionalidades

- Inicio de sesión de usuarios.
- Registro de usuarios.
- Agregar destinos turísticos.
- Mostrar la lista de destinos.
- Editar destinos.
- Eliminar destinos.
- Mostrar información del destino:
  - Nombre
  - País
  - Precio
  - Descripción
  - Imagen
- Almacenamiento de los destinos utilizando Firebase Firestore.
- Autenticación de usuarios mediante Firebase Authentication.
- Validación de los datos ingresados.
- Selección del país mediante un Spinner.

Tecnologías utilizadas

- Android Studio
- Kotlin
- Firebase Authentication
- Firebase Firestore
- RecyclerView
- XML para las interfaces
- Gradle
